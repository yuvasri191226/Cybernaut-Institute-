IMAGES FOLDER
=============

This folder holds images used by the announcement portal.

Expected files:
- logo.png       : Cybernaut Institute of Technology logo (used in the header on every page)
- Any other images added by the team (banners, icons, event posters, etc.)

How to use the logo:
1. Save the college logo as images/logo.png.
2. In each HTML file, replace the .logo-placeholder span with:
   <img src="images/logo.png" alt="Cybernaut Institute of Technology logo" width="80" height="80">
3. Always keep the alt text. Do not delete it.

Note: Member 2 may style the image size with CSS; the HTML only references the file.
