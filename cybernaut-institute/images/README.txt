IMAGES FOLDER (Member 2)
========================
The website looks for these photo files. If a file is missing, a navy gradient is
shown in its place, so the pages never look broken. No fake files are included.

To add a photo: save it here with the EXACT file name below. No code change needed.

  campus-hero.jpg      Home page hero (wide, landscape, at least 1920px wide)
  campus-building.jpg  About section, dashboard banners, gallery (1400px+)
  classroom.jpg        Facilities card and login page left panel
  computer-lab.jpg     Facilities card
  library.jpg          Facilities card and gallery
  research-lab.jpg     Facilities card
  events.jpg           Events card and gallery
  student-activity.jpg Events card and gallery
  graduation.jpg       Events card
  sports.jpg           Gallery

Tips: use bright, sharp landscape photos, 200 KB to 1 MB each (JPEG).
Best: real photos of your own campus. If you use stock photos (Unsplash/Pexels),
keep the on-page note "Representative images, not the actual Cybernaut campus."
and record the photographer and licence in images/CREDITS.txt.

logo.png: when the real logo is ready, replace the .logo-placeholder span in the
HTML with an <img> tag (see the comment inside each HTML file).
